# Chronos Scheduler - Deploy to Vercel in 5 Minutes ⚡

The fastest way to get your booking page live.

## ⚡ Super Quick (3 minutes)

### 1. Create GitHub Repo

```bash
# Create folder
mkdir chronos-scheduler
cd chronos-scheduler

# Init git
git init
git add .
git commit -m "Initial commit"
git branch -M main
```

Then go to [GitHub.com/new](https://github.com/new) and create repo, then:

```bash
git remote add origin https://github.com/YOUR_USERNAME/chronos-scheduler.git
git push -u origin main
```

### 2. Deploy to Vercel

1. Go to [Vercel.com](https://vercel.com)
2. Click "New Project"
3. Select your `chronos-scheduler` repo
4. Click "Import"
5. Click "Deploy"

**That's it! Your site is live!** 🎉

Default URL: `https://chronos-scheduler.vercel.app`

## ❓ FAQ

**Q: How do I get a custom domain?**
A: Vercel Dashboard → Settings → Domains → Add Domain

**Q: How do I update the site?**
A: Push to GitHub and Vercel deploys automatically!

**Q: Can I rollback to a previous version?**
A: Yes! Vercel Dashboard → Deployments → Click old deployment → "Promote to Production"

**Q: How do I add my backend?**
A: Set `NEXT_PUBLIC_API_URL` in Vercel environment variables

**Q: Is HTTPS included?**
A: Yes! All Vercel sites have free HTTPS

**Q: Can I use this with my own domain?**
A: Yes! Add domain in Vercel settings and update DNS
