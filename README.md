# Cons-istant

Minimal static site setup for Vercel deployment.

## Deploy on Vercel

1. Push this repository to GitHub.
2. In Vercel, click **Add New Project** and import this repository.
3. Keep the default settings (no build command is required).
4. Deploy.

`vercel.json` is included to:
- serve clean URLs
- route all paths to `index.html` (SPA-friendly routing)
