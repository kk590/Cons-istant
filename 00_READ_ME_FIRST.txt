🏗️ HOW TO DEPLOY IN 5 MINUTES
================================================================================

STEP 1: Create GitHub Repo (2 minutes)
  1. Go to: https://github.com/new
  2. Create repo named: chronos-scheduler
  3. Run git commands from GitHub

STEP 2: Deploy to Vercel (2 minutes)
  1. Go to: https://vercel.com
  2. Click: New Project
  3. Select: chronos-scheduler repo
  4. Click: Deploy

STEP 3: Done! (1 minute)
  ✅ Your site is live at: https://chronos-scheduler.vercel.app
